# Frontend Web Rules (`apps/web/AGENTS.md`)

These rules apply specifically to `apps/web/` and supplement the root `AGENTS.md`.

## Frontend Coding Conventions
- Write functional React components with explicit TypeScript interfaces for props and API payloads.
- Keep data-fetching types aligned with `packages/shared/schemas.json`.
- Always handle `loading`, `error`, and `empty` UI states explicitly in data views.
- Use semantic HTML elements (`main`, `section`, `header`, `table`) and accessible labels.
